# 🟣 Step-by-Step Instructions for Earning Points on the MyGate Network

![image](https://pbs.twimg.com/profile_banners/1856633768448241664/1735450816/1500x500)

## 🟣 Installing MyGate Network:
- Install the MyGate Network Node [Extension from the Chrome Web Store.](https://chromewebstore.google.com/detail/mygate-network-node/hajiimgolngmlbglaoheacnejbnnmoco)

![image](https://i.postimg.cc/DwFTw1SB/Screenshot-1.png)

## 🟣 Login to the Extension:
- Launch the extension and sign in with your MyGate Network account credentials.

![image](https://i.postimg.cc/Lsn09s3x/Screenshot-2.png)

## 🟣 Access the Web App:
- Access the [MyGate Network Web App](https://app.mygate.network/login?code=xPYDFl) and log into your account.

![image](https://i.postimg.cc/dQmnKdKq/Screenshot-3.png)

## 🟣 Start Earning Points:
- Ensure your device stays online with Chrome open to activate your node and start earning Points automatically.

![image](https://i.postimg.cc/cJnMktmG/Screenshot-4.png)
